# MNTN — راهنمای کوهنوردی

لندینگ‌پیج مدرن و مینیمال برای یک راهنمای کوهنوردی، با طراحی لایه‌ای (parallax-style) و تمرکز روی تجربه بصری.

---

## درباره پروژه

**MNTN** یک صفحه تک‌صفحه‌ای است که شامل این بخش‌هاست:

- هیرو با لایه‌های آسمان، کوه و زمین
- نوار ناوبری ساده
- سه بخش محتوایی درباره سطح کوهنورد، تجهیزات و نقشه/زمان‌بندی
- فوتر با لینک‌های مرتبط

ساخته‌شده با **HTML** و **CSS** خالص (بدون فریم‌ورک).

---

## اجرا

کافی است فایل را در مرورگر باز کنید:

```bash
cd Project1-MNTN
# سپس index.html را باز کنید
```

یا با یک سرور محلی ساده:

```bash
npx serve Project1-MNTN
```
