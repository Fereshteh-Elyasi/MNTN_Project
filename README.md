# MNTN — راهنمای کوهنوردی

لندینگ‌پیج مدرن و مینیمال برای راهنمای کوهنوردی، با طراحی لایه‌ای و تمرکز روی تجربه بصری.

ساخته‌شده با **HTML** و **CSS** خالص.

---

## مشاهده پروژه

فایل اصلی اینجا است:

**`Project1-MNTN/index.html`**

### روش ۱ — مستقیم
پوشه `Project1-MNTN` را باز کنید و روی `index.html` دوبار کلیک کنید.

### روش ۲ — سرور محلی

```bash
cd Project1-MNTN
npx serve .
```

سپس آدرسی که ترمینال نشان می‌دهد را در مرورگر باز کنید.
